# Panduan Aset Grafis (Sprites & UI Art)

Folder ini digunakan untuk menampung aset visual game.

### Struktur Subfolder:
- `items/`: Gambar objek konkret beresolusi tinggi dengan tepi halus (*transparent PNG*).
  - Dimensi: $512 \times 512$ piksel.
  - Contoh: `apel.png`, `ikan.png`, `udang.png`, `ember.png`, `obor.png`.
- `characters/`: Karakter maskot panduan anak (ekspresi senang, berpikir, dan merayakan).
- `ui/`: Tombol-tombol berukuran besar (minimal target sentuh $64 \times 64$ dp / $180 \times 180$ px), ikon volume, bintang apresiasi, dan latar belakang pemandangan (*landscape $1920 \times 1080$*).
